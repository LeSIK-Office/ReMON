# ReMON — AI 사무실

ReMON은 Mac의 자원과 로컬 AI 에이전트 세션을 함께 살피는 메뉴 막대 앱입니다. CPU·메모리·스왑·디스크의 상태를 보여 주고, 정리할 대상을 확인한 뒤 사용자가 직접 조치할 수 있습니다. 픽셀 사무실에서는 프로젝트를 방으로, 실행 중인 에이전트 세션을 사람으로, 앱과 시스템 자원을 기계로 표현합니다.

**최신 공개판:** 0.3.5(빌드 15) · [릴리스 기록](RELEASE_NOTES.md) · Apple Silicon · macOS 26 이상

## 설치와 시작

1. [Releases](../../releases/latest)에서 `ReMON-0.3.5.dmg`를 받습니다.
2. DMG를 열어 `ReMON.app`을 `응용 프로그램`으로 끌어 놓고 실행합니다.
3. 첫 실행의 권한 점검을 확인합니다. 필요한 권한과 로그인 실행 여부는 설정에서 다시 볼 수 있습니다.
4. 메뉴 막대의 ReMON 아이콘을 누르면 요약 패널이, 패널에서 **AI 사무실 열기**를 누르면 전체 창이 열립니다.

창을 닫거나 ⌘Q를 눌러도 메뉴 막대에서 계속 실행됩니다. 메뉴의 **완전히 종료…** 또는 ⌥⌘Q로 종료합니다. 현재 자동 업데이트는 지원하지 않으므로 새 버전의 DMG를 받아 앱을 교체합니다.

## 화면과 기능

### 메뉴 막대와 대시보드

- 메뉴 막대에는 움직이는 픽셀 직원과 선택한 시스템 수치가 나타납니다. 요약 패널에서 메모리·디스크 추세, 에이전트 세션, 정리 제안을 확인합니다.
- 대시보드는 CPU·RAM·디스크·스왑의 현재 값과 추세, 자원을 많이 쓰는 프로세스, 프로젝트별 세션을 보여 줍니다.
- 경보는 메모리 압박, 스왑 증가, 디스크 여유와 실제 정리 가능한 대상을 함께 고려합니다. **자동 메모리 정리 설정은 알림만 켜며 세션을 자동 종료하지 않습니다.**

### AI 사무실

- **방 = 프로젝트:** 실행 중인 세션의 작업 폴더를 기준으로 팀과 방을 묶습니다. 방을 선택하거나 검색해 해당 세션으로 이동할 수 있습니다.
- **사람 = 세션:** Claude Code·Codex CLI 등의 실행 상태를 일하는 중·입력 대기·쉬는 중·오래 쉼·고아로 구분합니다. 제목·마지막 활동·자원 사용량·복귀 가능성을 카드에서 확인합니다. 상태와 로그 연결이 추정이면 그 사실을 표시합니다.
- **로봇 = 하위 에이전트:** 식별 가능한 하위 작업을 원래 세션과 연결합니다. MCP 서버 같은 보조 프로세스는 독립 세션으로 과장하지 않습니다.
- **기계 = 앱·장치:** CPU와 메모리를 쓰는 앱, RAM·스왑·디스크를 장면에 배치합니다. 앱의 시작·종료, CPU 급등, 스왑과 디스크 변화를 실제 관측값으로 표현합니다.
- **사건과 방 안 짐:** 로컬 Git 기록의 커밋·푸시·배포 사건을 방에 반영합니다. 정리 가능한 워크트리·브랜치 등은 방 안 짐과 프로젝트 청소 목록으로 연결됩니다.
- 창의 좌측에는 프로젝트·위험 감지·청소 목록, 우측에는 기계 수치와 사건 기록이 있습니다. 장면의 연출은 상태를 설명하며 실제 조치는 카드나 확인 화면에서 시작합니다.

### 세션과 프로세스 관리

- 세션 카드에서 작업 폴더·기록 파일·터미널로 이동하고, 보호 고정과 이어 열기 명령을 확인할 수 있습니다.
- 쉬는 세션 정리나 강제 종료는 대상과 복구 가능성을 확인한 뒤 실행합니다. ReMON 자신, 시스템 프로세스, 보호 고정 대상과 터미널 호스트 등은 보호합니다.
- 실행 중인 앱·보조 프로세스는 별도로 보여 주고, 왜 실행 중인지 설명합니다. 끝내기 전에 되살릴 정보를 확보할 수 없는 프로세스는 종료하지 않습니다.
- 예상 회수량과 실행 뒤 실측값을 구분해 표시합니다. 종료·파일 이동·정리 결과는 로컬 작업 기록에 남습니다.

### 정리와 디스크 지도

- 정리 화면에서 개발 도구 캐시, AI 도구 데이터, 큰 파일, 시스템 데이터, 시작 항목, 남은 보조 프로세스를 분류해 봅니다. 항목별로 가능한 조치가 다르며 사용자 파일·AI 대화 기록·시스템 영역에는 보호 규칙을 적용합니다.
- 디스크 지도는 폴더와 묶음을 실제 할당량 기준으로 펼쳐 보여 줍니다. 지도에서 대상을 고르면 상세 정보와 가능한 조치를 확인할 수 있습니다. Docker·Homebrew·Xcode·다운로드·휴지통·Git 등의 묶음도 구분합니다.
- 파일 정리의 기본 경로는 휴지통 이동입니다. 다시 만들 수 있는 캐시에 한해 삭제가 허용될 수 있으므로 실행 전 목록과 조치 종류를 확인해야 합니다. ReMON이 휴지통을 자동으로 비우지는 않습니다.
- 프로젝트 청소는 Git의 병합·동등성, 미결합 커밋, 미추적 파일과 사용 중인 작업 공간을 확인합니다. 확인할 수 없는 항목은 청소 대상에서 제외합니다. 목록은 접거나 펼칠 수 있습니다.

### 복구함과 감사

- 세션·프로세스·파일·Git 정리 전에 가능한 복구 정보를 **로컬 금고에 먼저 기록**합니다. 기록에 실패하면 해당 종료나 이동을 진행하지 않습니다. 복구함에서 기록과 복구 방법을 확인합니다. 조치 종류에 따라 복구 가능 범위는 다릅니다.
- 사라진 세션은 종료 사건과 가능한 원인을 기록합니다. 원인을 확정할 근거가 없을 때는 추정으로 표시합니다.
- **감사**는 사용자가 직접 시작합니다. 로컬 규칙으로 판단하고, 조건에 해당하는 오래 쉰 세션은 로그인된 Claude CLI에 판정을 요청할 수 있습니다. 완료 후 판정과 사유를 보고서로 보여 주며 마지막 보고서 한 건을 로컬에 저장합니다. 감사에서 종료·재교육 대상이 나오면 실행 전에 확인을 받습니다.

## 에이전트 인식 범위

ReMON용 CLI를 따로 실행할 필요는 없습니다. 앱이 이 Mac의 프로세스와 로컬 기록을 읽습니다.

| 대상 | 현재 표시 방식 |
|---|---|
| Claude Code · Codex CLI · OpenCode | 실행 중인 프로세스를 세션으로 인식하고, 확인 가능한 로컬 기록을 연결 |
| Gemini CLI · Cursor Agent · Copilot CLI · Aider · Amp · Goose · Crush · Qwen Code · Factory Droid · Kimi CLI 등 | 프로세스 이름·경로·실행 인자로 인식. 기록 형식을 모르면 상태는 추정일 수 있음 |
| Codex Desktop · ChatGPT · Cursor 같은 GUI 앱 | 앱 자원은 기계로 표시. 앱 내부의 모든 대화를 사람 카드로 인식하지는 않음 |
| Orca 터미널 | 선택 사항. 있으면 탭·제목·복귀 위치 연결이 더 정확해짐 |

CLI가 설치만 되어 있고 실행 중이지 않으면 살아 있는 세션은 표시되지 않습니다. 지원하지 않는 실행 파일은 설정에서 직접 추가할 수 있지만, 해당 도구의 대화 기록·복귀 방식까지 자동으로 알게 되는 것은 아닙니다.

## 로컬 데이터와 권한

일반 모니터링과 정리에는 ReMON 서버나 계정이 필요하지 않습니다. 시스템 자원은 macOS API로, 에이전트 정보는 로컬 프로세스와 접근 가능한 기록으로 읽습니다. 원격 측정이나 대화 원문 전송 기능은 없습니다. **감사를 직접 실행해 Claude CLI 판정을 쓰는 경우에만 Claude CLI의 일반적인 외부 호출이 발생할 수 있습니다.**

| 데이터 | 기본 위치 |
|---|---|
| 복구 금고와 보관본 | `~/Library/Application Support/ReMON/Recovery/` |
| 지표 기록 | `~/Library/Application Support/ReMON/history.json` |
| 작업 기록 | `~/Library/Logs/ReMON/actions.jsonl` |

ReMON은 접근 가능한 범위에서만 측정합니다. macOS 권한 밖의 시스템 프로세스는 일부 지표가 빠지거나 별도 출처로 표시될 수 있습니다. 다른 사용자의 세션이나 다른 Mac의 세션을 원격으로 수집하지 않습니다.

## 소스에서 빌드

macOS 26 이상, Apple Silicon, Swift 6.2가 포함된 Xcode Command Line Tools가 필요합니다. SwiftPM 외부 패키지는 없으며 시스템 SQLite·zlib를 사용합니다.

```sh
swift build
.build/debug/ReMONChecks sessions
.build/debug/ReMON --scene-check all
zsh scripts/build.sh
```

`scripts/build.sh`는 개발용 ad-hoc 서명 앱을 `dist/ReMON.app`에 만듭니다. Developer ID 서명과 공증 배포에는 본인의 Apple 개발자 인증서와 공증 설정이 필요합니다. 패키징 절차는 [`scripts/package-release.sh`](scripts/package-release.sh)에 있습니다. 저장소가 공개되어 있어도 별도 이용 허락이 부여되는 것은 아닙니다.

## 알려진 범위

- 자동 업데이트와 다른 Mac의 원격 모니터링은 없습니다.
- Claude 세션의 컨텍스트 창 크기는 확인할 근거가 없어 점유율을 표시하지 않습니다. Codex도 기록과 연결이 불확실하면 보수적으로 표시합니다.
- 실제 Docker 엔진과 모든 터미널·장면의 사용 경로를 이 릴리스에서 전부 검증한 것은 아닙니다. 조치 전 미리보기와 복구 가능 여부를 확인해 주세요.
